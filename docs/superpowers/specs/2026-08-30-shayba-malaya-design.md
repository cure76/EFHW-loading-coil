# Шайба клеммы полотна (`EFHW_terminal_saddle_M4`)

Дата: 2026-08-30  
Статус: черновик, ждёт проверки

Связанный spec: `docs/superpowers/specs/2026-08-30-efhw-loading-coil-design.md`

## Цель

Отдельная печатная шайба-«грибок» на буртик каркаса EFHW: болт М4 из канала каркаса, шайба снаружи, металлическая шайба, петля одной жилы **П-274М**, гайка. Как на уже собранных катушках, но под текущие размеры (Ø буртика ≈ 58.2 мм, отверстие М4 = 4.5 мм).

Между **низом шляпки** и **уже севшей термоусадкой** на буртике — щель, куда проходит **одна** изолированная жила П-274М (max 2.3 мм) с запасом.

Порядок: сначала лак и термоусадка на всю катушку (болты торчат), потом шайба **сверху на усадку**.

## Вне скоупа

- Металлические шайба и гайка (покупные)
- `include` каркаса; шайба — свой файл
- Седло Diamond (изогнутая площадка без ножки)
- Две жилы пары в одной щели

## Файл

Файл: `EFHW_terminal_saddle_M4.scad`  
Один файл. Без `include`. STL — одна шайба. На катушку нужно **2** штуки.

## Customizer

Группа `[Shayba]`:

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `m4_d` | 4.5 | Зазорное отверстие под М4, мм (как в каркасе) |
| `flange_od` | 58.186 | Наружный Ø **голого** буртика, мм (echo каркаса) |
| `shrink_wall` | 0.6 | Толщина севшей термоусадки, мм (как превью каркаса) |
| `gap` | 3.0 | Зазор в свету между низом шляпки и **вершиной усадки**, мм |
| `hat_d` | 14 | Наружный Ø шляпки, мм |
| `hat_h` | 2.0 | Толщина шляпки, мм |
| `stem_od` | 7.6 | Наружный Ø ножки, мм |

`$fn`: `64` в `$preview`, `160` при рендере.

Производное: `saddle_od = flange_od + 2 * shrink_wall` (дефолт ≈ 59.386 мм). Седло режется по **этому** Ø, не по голому буртику.

Если в каркасе сменились провод, Ø или толщина усадки — подставить `flange_od` и `shrink_wall` из каркаса. Без `include`.

## Зазор и П-274М

По ТУ 16-505.221-78 изолированная жила П-274М **не больше 2.3 мм**.  
`gap = 3.0` = 2.3 + 0.7 мм запаса над **усадкой**. Путь жилы — **вдоль оси катушки**, под полями шляпки, вокруг ножки, затем петля на болт сверху.

## Твёрдотельная модель

Ось отверстия шайбы = **Z** (как в текущем файле). Шляпка в сторону **+Z**.

Поверхность посадки — цилиндр вдоль **Y**, радиус `R = saddle_od/2`, ось через `(0, 0, -R)`. Вершина **усадки** в `z = 0` (при `x = 0`).

1. **Ножка:** цилиндр Ø `stem_od` от `z = -2` до `z = gap` (запас вниз, чтобы седло вырезалось).
2. **Шляпка:** цилиндр Ø `hat_d` от `z = gap` до `z = gap + hat_h`. Низ шляпки — плоскость `z = gap`. Вдоль образующей катушки (`x = 0`) зазор до усадки постоянен и равен `gap`. Поперёк болта кривизна щель только увеличивает; второй цилиндр «R+gap» по шляпке не нужен.
3. **Отверстие М4:** цилиндр Ø `m4_d` через всю деталь (`z` от −3 до `gap + hat_h + 1`).
4. **Седло ножки:** вычесть цилиндр Ø `saddle_od`, ось Y, центр оси `(0, 0, -R)`. Ножка садится на усадку без качания.

Один модуль `shayba()`, без копипаста двух `difference` как сейчас.

## `echo()`

- `m4_d`, `flange_od`, `shrink_wall`, `saddle_od`, `gap`, `hat_d`, `stem_od`
- напомнить: жила П-274М ≤ 2.3 мм; на катушку 2 детали; седло под усадку, не под голый пластик
- если в каркасе другой `flange_od` / `shrink_wall` — подставить их сюда

## Ограничения

Не строить геометрию и `echo` ошибки, если:

- `gap < 2.3`
- `m4_d >= stem_od`
- `stem_od >= hat_d`
- `flange_od <= 0` или `hat_h <= 0` или `shrink_wall < 0`

## Сборка (физика)

1. Каркас: намотка, лак, отводы на М4, термоусадка на всю катушку включая буртики; стержни болтов снаружи (как spec каркаса).
2. Надеть шайбу седлом **на усадку** (не на голый буртик).
3. Одну жилу П-274М завести в щель под шляпку, вокруг ножки; конец — петля на болт.
4. Металлическая шайба, гайка. Вторая такая же клемма на другом конце катушки.

## Проверка

1. F5: грибок, седло снизу ножки, шляпка выше, сквозное отверстие.
2. F6: один manifold.
3. Зазор: расстояние от плоскости `z = gap` до вершины вычитаемого цилиндра усадки (`z = 0`) равно 3 мм.
4. Смена `flange_od` или `shrink_wall` меняет `saddle_od` и кривизну седла; `m4_d` — диаметр отверстия.
5. `gap = 2.0` → ошибка, нет тела.
