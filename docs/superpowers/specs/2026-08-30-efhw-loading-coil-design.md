# Параметрический каркас удлиняющей катушки EFHW

Дата: 2026-08-30  
Статус: черновик, ждёт проверки

## Цель

Заменить вручную подогнанную бобину в OpenSCAD одним файлом с Customizer: по индуктивности и проводу считается **однослойная** удлиняющая катушка для антенны EFHW, в печать идёт только каркас. Значения по умолчанию: **100 мкГн**, **ПЭТВ-2 1 мм**, диаметр намотки **55 мм**. После лака готовая катушка закрывается термоусадкой **на всё тело, включая буртики**. Канал трубы остаётся **сквозным** для охлаждения.

## Вне скоупа

- Многослойная намотка
- Крышки на торцах или осевые проушины
- Печатная спираль провода
- Термоусадка как деталь в STL

## Файл

Переписать на месте: `EFHW_Loading_Coil_100_mkgn_1mm.scad`  
Один файл. Без `include`. STL всегда только каркас.

## Входы Customizer

Группа `[Coil]`:

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `L_uH` | 100 | Целевая индуктивность, мкГн |
| `winding_d` | 55 | **Наружный** диаметр каркаса = диаметр намотки, мм |
| `wire_cu_d` | 1.0 | Диаметр меди, мм (для echo / подписи) |
| `wire_od` | 0 | Наружный диаметр изолированного провода, мм. `0` = авто |

Группа `[Former]`:

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `wall` | 2 | Толщина стенки трубы, мм |
| `flange_len` | 14.5 | Длина каждого буртика вдоль оси, мм |
| `flange_over_wire` | 0.5 | Насколько буртик выше наружной поверхности провода, мм |
| `m4_d` | 4.5 | Зазорное отверстие под М4, мм |

Группа `[Preview]`:

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `show_winding` | false | Оболочка обмотки только в F5 |
| `show_shrink` | false | Оболочка термоусадки только в F5 |
| `shrink_wall` | 0.6 | Толщина севшей усадки для превью, мм |

`$fn`: `64` в `$preview`, `160` при рендере.

### Авто `wire_od`

Если `wire_od == 0`, взять приращение эмали по максимуму ПЭТВ-2 (ТУ 16-705.110-79) для 1,00 мм:

`wire_od_eff = wire_cu_d + 0.093`

Для меди 1,00 мм это **1,093 мм**. После измерения реального провода штангенциркулем задать `wire_od`. Шаг витка и отверстия отводов всегда от `wire_od_eff`, не от `wire_cu_d`.

## Производная геометрия

Все длины в мм.

- Внутренний диаметр: `inner_d = winding_d - 2 * wall` (должен быть `> 0`)
- Шаг (виток к витку): `pitch = wire_od_eff`
- Средний диаметр намотки: `d_mean = winding_d + wire_od_eff`
- Средний радиус: `r = d_mean / 2`
- Диаметр отверстия отвода: `lead_d = 2 * wire_od_eff`
- Наружный диаметр буртика: `flange_od = winding_d + 2 * (wire_od_eff + flange_over_wire)`
- Число витков `N`: решить Уилера 1928 для однослойной воздушной катушки, округлить до ближайшего целого ≥ 1
- Окно намотки: `winding_len = N * pitch`
- Полная длина: `length = winding_len + 2 * flange_len`

### Уилер 1928 (дюймы)

Перевести `r` и `pitch` в дюймы. `L` — это `L_uH`.

`L = r² N² / (9r + 10 l)`, где `l = N * pitch`

Квадратное уравнение по `N`:

`r² N² − 10 L pitch N − 9 L r = 0`

`N_exact = [10 L pitch + sqrt((10 L pitch)² + 36 L r³)] / (2 r²)`

`N = max(1, round(N_exact))`

Затем `L_actual` по той же формуле с целым `N` и `l = N * pitch`.

**Проверка на дефолтах:** `N` ≈ 51, `winding_len` ≈ 55,7 мм, `L_actual` ≈ 99–100 мкГн, `flange_od` ≈ 58,2 мм, `length` ≈ 84,7 мм. Если `echo` в OpenSCAD разойдётся больше чем на ~1 виток или ~5 мкГн — ошибка переноса формулы.

## Твёрдотельная модель

Система координат: ось трубы = Z, центр в начале координат (как в текущем файле).

1. **Труба:** `cylinder(h=length, d=winding_d, center=true)` минус `cylinder(h=length+2, d=inner_d, center=true)`.
2. **Буртики:** два кольца **снаружи** трубы (канал не сужать). Центры в  
   `z = ±(length/2 − flange_len/2)`.  
   Снаружи `flange_od`, внутри `winding_d`, высота `flange_len`.
3. **Отверстия** (одна сторона каркаса, −Y, как в текущем файле): на каждом конце вычесть два радиальных цилиндра от оси за наружную поверхность (сквозь одну стенку в канал).

**М4:** по осевому центру каждого буртика. Диаметр `m4_d`.

**Отводы:** у начала обмотки, сразу за буртиком:

`z_from_end = flange_len + lead_d/2 + 1`

Если при этом между двумя отверстиями отводов останется меньше `lead_d` обмотки, ставить отверстия на 25% и 75% `winding_len`.

Отверстия **не сквозные на весь диаметр**: только одна стенка, оба на −Y.

Не копировать модули отверстий на каждый конец; один helper и `for` по двум концам.

## Превью (никогда не в STL)

Оградить `$preview && show_*`.

- Обмотка: полая трубка в окне намотки, внутри `winding_d`, снаружи `winding_d + 2 * wire_od_eff`. Не спираль.
- Термоусадка: полая трубка на всю `length`, внутри `flange_od`, снаружи `flange_od + 2 * shrink_wall`. Цвет с прозрачностью.

## Рецепт `echo()` (каждый F5/F6)

Печатать:

- `N`, `winding_len`, `L_actual` (мкГн)
- `length`, `flange_od`, `inner_d`
- `lead_d`, `m4_d`
- Минимальный внутренний Ø термоусадки до усадки: `flange_od + 2` (мм), чтобы трубка ещё надевалась на буртики
- Сборка: лак → отводы на М4 (гайка внутри канала) → термоусадка на всю катушку, стержни болтов снаружи

## Ограничения

Если `inner_d <= 0`, или `N_exact` не конечен, или `winding_len <= 0`: `echo` понятной ошибки и **не** строить геометрию.

Если `lead_d >= flange_od / 2`: `echo` предупреждения (отверстие огромное относительно каркаса), но вырезать, если остальные проверки прошли.

## Сборка (физика, не CAD)

1. Напечатать каркас (для улицы лучше PETG, не PLA).
2. Намотать `N` витков виток к витку в окне; начало и конец через отверстия отводов.
3. Покрыть лаком; высушить.
4. Болт М4 через каждый буртик; гайка внутри канала; отводы катушки на те же болты.
5. Термоусадка с клеем (2:1 или 3:1) на **весь** каркас, включая буртики. Расширенный внутренний Ø ≥ значения из `echo`. Болты остаются снаружи усадки.
6. Измерить L-метром. Подстраивать шагом или снятием витка, а не перепечаткой, если `L_actual` не слишком далеко от цели.

## Структура кода

Шесть пересекающихся модулей заменить на:

- параметры + группы Customizer
- функции: `in(mm)`, `petv2_od`, `wheeler_n`, `wheeler_L`
- `module former()` — объединение трубы и буртиков, вычитание отверстий
- `module preview_winding()`, `module preview_shrink()`
- один вызов в конце файла + `echo`

Комментарии на русском, как в текущем файле.

## Проверка

1. Открыть файл в OpenSCAD, F5 с дефолтами: одна полая труба, два буртика, четыре отверстия с одной стороны, без обмотки/усадки.
2. Включить флаги превью: обмотка между буртиками; усадка закрывает буртики.
3. F6: тел превью нет; сетка — один manifold-каркас.
4. Сверить `echo` с контрольными числами выше.
5. Сменить `L_uH` на 50: `N` и `length` уменьшаются; отверстия по-прежнему с одной стороны и в окне намотки.
6. Задать `wire_od` измеренным значением (например 1,12): шаг, `flange_od` и `lead_d` следуют за ним.
